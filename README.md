# Phase1A

A personal food-logging and tracking application built to make recording and managing food data easier.

## Features
- Database-backed system for logging food items and quantities
- Integrated a large language model through an API to assist with interpreting and recording new entries
- Confidence ratings to help identify entries that may need manual review
- Deployed using Railway

See `SPEC.md` for the full database schema (presets and entries tables).

## Tech stack
JavaScript, Node.js, SQL
